## 📌 Description
This project demonstrates modern layout techniques using CSS Flexbox and Grid. It is built as a responsive multi-page website without external CSS frameworks or float layout.

## 🚀 Pages & Structure
1. **Part 1: Flexbox (`index.html`)**
   - Responsive Navigation Bar with logo and links.
   - Featured Attractions section using Flexbox row cards with hover animation.
2. **Part 2: Grid System (`grid.html`)**
   - Page layout structured with CSS `grid-template-areas` (Header, Sidebar, Main Content, Footer).
   - Visual Gallery with a 3-column CSS Grid and dynamic hover captions overlay.
3. **Part 3: Combining Flexbox & Grid (`portfolio.html`)**
   - Hybrid layout combining Grid for page sections/project grid and Flexbox for individual cards and interactive controls.
